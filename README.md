Student Grade Management System

A menu-driven Student Grade Management System developed using C++ to manage student records and analyze academic performance.

Features

- Add new students with unique IDs and grades.
- Display all students in a formatted table.
- Search for students by ID.
- Calculate total marks, averages, and percentages.
- Determine pass/fail status for each subject and overall performance.
- Display detailed student results and failed subjects.
- Calculate class statistics, including class average, highest and lowest averages, and success rate.
- View a complete class summary.
- Delete student records with confirmation.
- Validate user input and grade ranges.

Subjects

- Mathematics
- English
- Computer Science
- Physics
- Statistics

Technologies Used

- C++
- Arrays and functions
- Loops and conditional statements
- Input validation and formatted output

Limitations

- The system supports up to 100 students.
- Student records are stored in memory and are not saved after the program closes.

How to Run

Open the project in Code::Blocks, build it, and run the program.
